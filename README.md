# 智域争锋·能源纪元

基于 Web 的 2.5D 回合制大富翁风格策略游戏，主题为 **AI 产业链与能源经济**。纯前端实现（Three.js + 原生 ES6 JavaScript），无后端依赖。

## 运行方式

由于使用 ES Module，需要通过本地 HTTP 服务器打开（直接双击 `index.html` 会因浏览器安全限制无法加载模块）：

```bash
# 在项目根目录执行任意一种：
python3 -m http.server 8000
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8000`。Three.js 通过 CDN（jsdelivr）加载，首次运行需联网。

## 玩法速览

- **模式**：单人 vs 3 AI，或 2~4 名本地玩家轮流操作。
- **胜利条件**：最先获得 **10 AI 积分**。
- **棋盘**：24 格环形，包含起点、发电站⚡、芯片厂🖥️、AI公司🧠、资源格💎、事件格❓、监狱格🚧。
- **回合流程**：掷骰移动 → 格子触发（购买/过路费/资源/事件/监禁）→ 资产产出 → 自由交易 → 结束回合。
- **产业联动**：同时拥有发电站、芯片厂、AI 公司各至少 1 座时，每个 AI 公司从「耗 2 能源产 1 积分」升级为「耗 1 能源产 2 积分」。
- **事件卡**：20 张随机事件（能源补贴、黑客攻击、电力危机、市场泡沫……），抽到立即生效。
- **交易**：玩家间可任意交换算力/能源；也可向银行购买能源（基础价 2 算力/能源，贸易战期间涨价）。
- **破产**：无法足额支付过路费即出局，资产归还银行；仅剩一名玩家时其直接获胜。

## 项目结构

```
index.html        页面骨架 + Three.js importmap
css/style.css     UI 叠加层样式（深色科技风）
js/config.js      棋盘 24 格、20 张事件卡、常量配置
js/scene3d.js     Three.js 2.5D 场景：地块、棋子、骰子动画
js/game.js        回合状态机、规则、事件效果、产出、交易、胜负
js/ai.js          简单 AI（70% 概率购地、交易估值、目标选择）
js/ui.js          DOM 面板、弹窗、日志、开局设置
js/main.js        入口
```
